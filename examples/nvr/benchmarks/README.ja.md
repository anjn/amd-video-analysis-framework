# デモ用の品質評価データ

`person-review.json` には、M01–M16 の美術館映像 16 本について、10 秒時点のフレームを
960 × 540 で表示して確認した、53 個の人物ボックスを記録しています。高さが 54 ピクセル未満のボックスは除外しています。最初の検出結果を目視で確認し、明らかな美術作品、支柱、重複の検出を取り除きました。大きく隠れている人物や判別できない人物は網羅的にはアノテーションしていません。検出器の結果を起点にしたセットのため、ベースラインに有利になる場合があります。

`appearance-review.json` には、小規模な検索確認のために、確認済みの切り出し画像 52 枚と外観ラベルを記録しています。重なりがあって判別があいまいな切り出し画像は除外しました。これらのラベルは、本番用のカメラ間人物同定の機能を裏付けるものではありません。どちらのファイルにも、トラッキングの IDF1 評価に使える時系列の軌跡は含まれていません。

元の映像はローカルの `~/work/videos` に置いたままです。フレーム、切り出し画像、RTSP で配信する独立した 30 秒の 1080p 素材は `examples/nvr/scripts/prepare_ai_fixture.py` で再作成できます。既定の出力先は `artifacts/ai-benchmark` で、バージョン管理の対象外です。元の映像を上書きすることはありません。品質確認スクリプトには、ローカルの model-export Python
環境が必要です。実行方法と結果の解釈は [AI 性能](../../../docs/dev/nvr/nvr-ai-performance.ja.md) を参照してください。モデルのチェックポイントとコンパイル済みモデルはリポジトリに含めていません。

ユーザーによると、元の 10 分間の映像 16 本に登場する人物は合計 40 人です。確認済みのサブセットでは 40 人全員をアノテーションしていません。統合負荷試験では
30 秒の抜粋を使うため、ループの境界で余分なトラック ID が生じることがあります。ID はカメラごとに独立しています。ID の合計数を 40 と比べて、人物同定の精度指標として扱わないでください。
